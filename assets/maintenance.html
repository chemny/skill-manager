如何安装

选择安装来源填写仓库或下载链接，也可以选择本地文件夹或 ZIP。一个仓库可能包含多个 Skills。
选择 Agent 和安装位置确认由哪个 Agent 使用，以及文件将保存到哪个目录。
选择 Skill点击“安装 skills”，从结果中选择需要安装的内容。
安装完成选择需要的 Skill 后直接安装。已有同名目录不会被覆盖；安装后可能需要 Agent 重新加载。
