# Agent Icons

The maintenance page bundles brand SVGs inline as data URLs. No CDN or network
request is needed when rendering a Skill list or the sidebar. Existing Codex,
Claude Code, Hermes and OpenClaw marks are unchanged. Unknown custom Agents use
their first two name characters, not the former generic circle.
